# Project Name: BazarDor

# Short Description About Project
BazarDor is a web application for browsing products, exploring market price trends, and viewing product details.

## Technologies Used
- Next.js, React, TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- Google & GitHub OAuth
- Vercel

## Key Features
1. Rising and falling product price trends.
2. Product browsing and detailed product pages.
3. Email, Google, and GitHub authentication.
4. User profile management.
5. Responsive and user-friendly interface.
